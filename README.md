# SafeDrive AI

Driver risk prediction and safety intervention system. Three modules feed one fusion engine that raises alerts and suggests safer routes.

| Module | Owner |
|---|---|
| Driver behaviour detection, crash risk and accident severity | Lekhya |
| Alcohol impairment detection | Srinivas |
| AI integration: fusion, alerts, routes, live dashboard | Likhitha |

## Datasets (created by the team, 100 % SYNTHETIC)
All three modules are trained on datasets generated by the scripts in `dataset_generators/` (fixed seed 2026, fully reproducible).
No real driver, vehicle, person or crash was recorded. Results describe controlled synthetic benchmarks, not real-world accuracy.

| Dataset | File(s) | Size | Used by |
|---|---|---|---|
| SafeDrive-Sim-IMU | `data/driver_behavior/trip_1..12/` | 12 trips, 184 labelled events, 9 classes | `src/behavior.py` |
| SafeDrive-Sim-Alcohol | `data/alcohol/safedrive_sim_alcohol.csv` | 2,000 sessions, 60 simulated participants | `src/alcohol.py` |
| SafeDrive-Sim-Crash | `data/crash/safedrive_sim_crash.csv` | 30,000 simulated crashes, Coimbatore-area box | `src/crash.py` |

Regenerate: `python dataset_generators/generate_driver_behavior.py`, `generate_alcohol.py`, `generate_crash.py`  
IEEE DataPort submission packages (documentation, cover images, form text): `ieee_dataport/` - see `ieee_dataport/PUBLISHING_GUIDE.md`.

## Architecture
Smartphone IMU, in-cabin sensors, accident history and live weather/GPS feed the three modules. The fusion engine combines their outputs into one risk level and triggers a driver alert, an emergency-contact notification and a safer route.

## Run
Windows: `run_windows.bat`  
Mac/Linux: `./run_mac_linux.sh`  
Manual: `pip install -r requirements.txt`, then `python train_all.py` (a few minutes), then `python src/server.py`, and open http://localhost:8000

## Folders
- `dataset_generators/` scripts that create the synthetic datasets and the IEEE DataPort packages
- `src/` backend (server, models, fusion)
- `web/` dashboard
- `data/` datasets
- `models/` trained models, `reports/` metrics
- `ieee_dataport/` ready-to-upload dataset packages
- `team.json` team and responsibilities

## Note
Emergency SMS/call is simulated. Live weather in the dashboard comes from the free Open-Meteo API.
